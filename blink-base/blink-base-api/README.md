base-api 这个工程是作为feign 服务给其他服务调用的

一般在微服务开发中 某个服务中供外部调用的接口 封装为feign模块 打包到私服maven
然后其他微服务要调用的话 在导入这个封装的feign模块

实际团队开发中 feign接口修改频繁 又由于依赖链条的存在 往往其他服务也要刷新依赖包 造成多个项目需要重新编译或者重新打包
而且有grale本地缓存的存在 其他人员往往需要手动删除缓存包 太繁琐 影响太大

所以弃用了这种封装开发方案  这里保留 仅仅作为样例存在！

后续采用 在调用方封装feign的方案 按需编写接口 复制或者重写 DTO均可
这样实际依赖更细粒化,不会牵一发二动全身 坏处就是对整个项目来说多了重复的DTO 这是可以接受的
