# blink-base-app

使用 blink 框架构建的 RBAC 后台管理服务。核心功能包括用户、角色、菜单、权限、字典、组织管理，以及工作流引擎、数据权限过滤等企业级功能。

## 模块结构

```
blink-base-app/
├── controller/          # 控制器层
├── service/             # 服务层
│   └── impl/           # 服务实现
├── mapper/              # MyBatis Mapper
├── entity/              # 数据实体（DO）
├── dto/                 # 数据传输对象
│   ├── req/            # 请求 DTO
│   ├── rsp/            # 响应 DTO
│   └── vo/             # 视图对象
├── dubbo/               # Dubbo 服务实现
├── datascope/           # 数据权限过滤
│   ├── constants/      # 规则类型枚举
│   ├── handler/        # 过滤处理器
│   └── merge/          # 规则合并策略
├── component/           # 组件
├── config/              # 配置类
├── constants/           # 常量定义
└── utils/               # 工具类
```

## 功能模块

### 用户管理

用户是指后台管理人员，登入系统操作或查看业务数据。

| 功能 | 说明 |
|------|------|
| 用户分页列表 | 展示基本信息，可多条件查询 |
| 添加用户 | 填写基本信息，可选分配角色和组，密码加盐加密 |
| 删除用户 | 弹窗确认，超级管理员不可删除 |
| 修改用户 | 基本信息修改，组织和角色重新选择 |
| 用户详情 | 包含基本信息、组织和角色信息 |
| 分配组 | 树形结构选择组织，支持批量分配 |
| 分配角色 | 列表搜索选择，支持多角色，权限取并集 |
| 用户登录 | 登录名+密码验证，获取 Token |
| 用户锁定 | 连续 3 次密码错误自动锁定 |
| 登录用户列表 | 查看登录信息，提供强制下线功能 |
| 密码重置 | 重新设置用户密码 |
| 首次登录改密 | 首次登录强制修改密码 |

**登录特性：**
- 有状态 Token 管理（支持 JWT 切换配置）
- 同一用户同时只能登录一次（新登录踢出旧登录）
- Token 自动续期（过期前 5 分钟活跃则延长 30 分钟）
- 滑块验证码验证

### 角色管理

角色即用户拥有的身份，每个角色可配置关联菜单或权限。

**角色类型：**
- **系统内置角色**：系统未投入生产就配置在数据库中的角色（如超级管理员、系统管理员）
- **自定义角色**：使用本系统创建的角色

**超级管理员特性：**
- 具有系统的一切权限
- 不参与角色的管理（只读性）
- 不保存任何超级管理员关联数据
- 权限标识为 `*:**`

| 功能 | 说明 |
|------|------|
| 角色列表 | 分页列表，提供角色基本信息，多条件查询（支持按用户条件查询） |
| 添加角色 | 填写基本信息，可分配菜单或权限 |
| 删除角色 | 物理删除，存在关联用户的角色不可删除 |
| 修改角色 | 修改基本信息，重新分配菜单或权限 |
| 角色详情 | 包含基本信息、已分配用户列表、权限和菜单列表 |
| 分配菜单 | 支持多角色批量分配 |
| 分配权限 | 支持多角色批量分配 |

### 菜单管理

菜单保存系统前端页面的导航菜单和功能按钮，用于不同角色的用户展示不同的菜单。

**设计说明：**
- 菜单本身不是权限，和权限独立分离
- 仅作为前端渲染控制
- 支持顺序、显隐控制

| 功能 | 说明 |
|------|------|
| 菜单树形列表 | 非分页，提供菜单基本信息，多条件查询 |
| 添加菜单 | 添加菜单，建议避免超过 3 层深层菜单 |
| 删除菜单 | 物理删除，无法删除拥有子菜单的菜单 |
| 修改菜单 | 修改菜单基本信息 |
| 菜单详情 | 查看菜单信息 |

### 权限管理

每个权限具有唯一的权限标识，形式 `xxx:aaa:yyy`。

**权限类型：**
- **接口权限**：对应 API 接口，URL 与权限标识一对一
- **数据权限**：通过数据过滤规则控制数据范围

| 功能 | 说明 |
|------|------|
| 权限列表 | 分页，提供权限基本信息，多条件查询 |
| 添加权限 | 添加权限 |
| 删除权限 | 无法删除拥有子权限的权限 |
| 修改权限 | 修改权限基本信息 |
| 权限详情 | 查看权限信息 |

### 组织管理

| 功能 | 说明 |
|------|------|
| 组织树形列表 | 非分页 |
| 添加组织 | 添加组织 |
| 删除组织 | 存在关联用户时无法删除 |
| 修改组织 | 修改组织信息 |
| 组织详情 | 查看组织信息 |

**支持的规则类型：**

| 规则类型 | 说明 |
|----------|------|

| 自定义SQL | 自定义 SQL 条件过滤 |
| 关联过滤 | 通过关联表过滤数据 |

| 功能 | 说明 |
|------|------|
| 规则列表 | 分页查询过滤规则 |
| 新增规则 | 配置实体类、字段、匹配规则 |
| 更新规则 | 修改过滤规则 |
| 删除规则 | 删除过滤规则 |
| 刷新缓存 | 刷新数据权限缓存 |
| 获取实体列表 | 获取可配置过滤的实体类 |
| 获取字段列表 | 获取实体类的字段信息 |

## 快速启动

### 1. 配置中间件

确保以下中间件已启动：
- MySQL 8.0+
- Redis 7.0+
- Nacos 2.3+

### 2. 修改配置

修改 `application.yml` 中的数据库、Redis、Nacos 连接信息。

### 3. 初始化数据库

执行 SQL 脚本创建数据库表结构和初始化数据：

```bash
# 创建数据库（如不存在）
CREATE DATABASE blink DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 1. 创建表结构
mysql -u root -p blink < sql/blink.sql

# 2. 导入初始化数据
mysql -u root -p blink < sql/init.sql
```

初始化数据包含：
- 超级管理员用户（账号：`admin`，密码：`123456`）
- 超级管理员角色
- 系统菜单
- 角色菜单关联
- 字典类型和字典数据
- 系统配置

### 4. 启动服务

运行 `BlinkBaseAppApplication` 主类。

```bash
# 或使用 Gradle
./gradlew :blink-base:blink-base-app:bootRun
```

服务默认端口：8001
